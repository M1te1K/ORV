# ORVI Simulator

Шуточная программа для Windows 10/11, имитирующая симптомы простуды (ОРВИ) на компьютере.

## Что делает

Каждые **3–7 секунд** случайно (по ~33.3%) выполняется одно из трёх действий:

- **Чих** — проигрывается звук чиха и открывается случайное приложение: браузер по умолчанию,
  Диспетчер задач, экранная клавиатура (`osk.exe`) или Проводник.
- **Кашель** — проигрывается звук кашля, все видимые окна на экране примерно на 1.2 секунды
  начинают дрожать, затем возвращаются на исходное место.
- **Сморкание** — проигрывается звук сморкания, системная громкость случайно немного
  повышается или понижается.

Дополнительно, независимо от основного действия, с шансом ~18% в каждом цикле включается
эффект **"температуры"** — экран на 2.5–4.5 секунды слегка подсвечивается красным
(полупрозрачный оверлей, без звука).

### Звуки

Файлы лежат в [`sounds/`](sounds/) и вшиты внутрь exe при сборке (`--add-data`), поэтому
переносить их отдельно не нужно. Все три — с [Pixabay](https://pixabay.com), лицензия
[Pixabay Content License](https://pixabay.com/service/license-summary/) (бесплатно для
любого использования, атрибуция не требуется):

- `sneeze.mp3` — Sneeze SFX, DRAGON-STUDIO
- `cough.mp3` — Cough, Fabrizio84 (Freesound)
- `blow_nose.mp3` — Blowing Nose, jackthemurray (Freesound)

## Запуск

Готовый исполняемый файл: [`dist/ORVISimulator.exe`](dist/ORVISimulator.exe)

Просто запустите `ORVISimulator.exe` — программа не показывает окон и работает в фоне
(в списке процессов Диспетчера задач будет видна как `ORVISimulator.exe`).

## Как остановить

- Горячая клавиша **Ctrl + Alt + Shift + Q** — корректно завершает программу.
- Либо через Диспетчер задач: найти процесс `ORVISimulator.exe` и снять задачу.

Программа не прописывается в автозагрузку, не создаёт файлов и записей в реестре —
после завершения процесса от неё не остаётся следов.

## Важно

Предназначено только для розыгрыша на **своём собственном компьютере** или на компьютере
человека, который **знает и согласен** на такой розыгрыш (например, друг/коллега в курсе
шутки). Не устанавливайте это на чужие устройства без согласия.

## Сборка из исходников

Исходный код: [`orvi.py`](orvi.py)

```bash
python -m pip install pyinstaller pywin32
python -m PyInstaller --onefile --noconsole --name ORVISimulator --add-data "sounds;sounds" orvi.py
```

Готовый файл появится в `dist/ORVISimulator.exe`.

## Настройки

Все параметры (интервал, амплитуда дрожания, вероятность температуры и т.д.)
находятся в начале файла `orvi.py` в блоке `# Настройки` — их можно поменять
и пересобрать exe.
